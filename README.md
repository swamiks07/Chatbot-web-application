# Chatbot Web Application

A responsive chatbot web application developed using React.js, JavaScript, HTML, and CSS. The application provides an interactive conversational interface where users can send messages and receive predefined chatbot responses.

## Features

- Responsive chatbot interface
- Interactive conversational user experience
- Message input and conversation display
- Chatbot response handling
- Predefined responses using an external JavaScript chatbot library
- React-based component structure

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- External JavaScript Chatbot Library
